== 动词的て形、た形

=== 三类动词（カ变、サ变）

. する => して した
. 来る => 来て 来た

=== 二段动词（上一段、下一段）

る变成て、た，例如：

. 食べる => 食べて 食べた
. 調べる => 調べて 調べた

=== 一类动词（五段动词）

|原形|变形|例子

|く | いて いた |磨く みがく => 磨いて 磨いた
|ぐ | いで いだ |急ぐ いそぐ => 急いで 急いだ

== 语法

=== 动て动（相继发生）

表述两个以上的动作依照时间顺序相继发生时，可以使用“动词て形+动词”的形式来表示。

[literal]
----
* 昨日 デパートヘ 行って、買い物しました。（用て形）
* 昨日 デパートヘ 行きました。そして、買い物しました。（不用て形）
* 家ヘ 帰って、宿題を します。
* 図書館ヘ 行って 本を 借りて、家ヘ 帰ります。
* 昨日、私は 映画館ヘ 行って 映画を 見ました。
----

=== 动てから动（相继发生）

表述两个以上的动作按照时间顺序相继发生时，也可以使用“动词て形+から+动词”的形式表达。其语义和“动词て形+动词”基本相同，但“てから”不能在同一个句子中重复使用两次以上使用。

[literal]
----
* 李さんは 毎晩 ラジオを 聞いてから 寝ます。
* 昼ご飯 食べでから 出かけます。
* 家ヘ 帰ってから、もう一度 日本語の勉強を します。
* 昨日、私は 映画館ヘ  行ってから 映画を 見ました。
----

=== 动ください

求某人做某事时使用“动词て形+ください”。

食べる => 食べてください

[literal]
----
* ここに 住所と 名前を 書いて ください。
* この荷物お 航空便で 送って ください。
* 私に 教えってください。
----
=== 名（场所）を动

经过的场所用“を”表示，常用的动词有“通ります”，“渡ります”，“過ぎます”等。此外，“を”与动词“出ます”“卒業します”等搭配使用时，表示离开的场所。

[literal]
----
* この バスは 駅前 を 通ります。
* この 道を まっすぐ 行って、橋 を 渡って ください。
* 李さんは 毎朝 七時に 家 を 出ます。
* 私は 来年 大学 を 卒業します。
----

=== 表达及词语讲解

==== 句子的连接方法。

昨日、私は 図書館ヘ 行って、勉強を しました。そらから 家ヘ 帰って、手紙を 書きました。

==== 買い物します サ变 名词+する

買い物します==買い物[を]します，都可以加上/省略を。
|===
|汉字词|出張します、旅行します、料理します、食事します、仕事します、掃除します、散歩します、整理します
|外来词|ジョギングします、ファックスします、コピーします
|===


==== 駅前 VS 駅の前

* この パスは 駅前を ろおりますか。
* 昨日 駅の 前で 森さんに 会いました。

==== なかなか（表示程度的副词）

. 李さんの 日本語は なかなか 上手ですね。
. 小野さんの 料理は なかなか 美味しいです。

なかなか 表示比预想的程度高。不能对长辈、上级使用。

==== ~て くださいませんか

是一种更礼貌的说法，不是表示否定。

* 後で 写真も 見て くださいませんか。
* スケジュール表を ファックスで 送って くださいませんか。

==== もう

除了表示已经，还可以表示就要、马上。例句：

李さん、もう 会社を 出ますか。

==== すみませんが、~（搭话）

==== そうして ください

そうする=>そうして。请你那样做。

[literal]
----
* 速達で 出しますか。
  ええ、そうして ください。
* 暗いですね。電気を つけますか。
  ええ、そうして ください。
----

==== お金お 下ろします

“取钱”的意思。

== 课文

[literal]
----
A:今日の 午後は 何を しますか。
B:図書館ヘ 行って、勉強を します。
  それから 、家へ 帰って、手紙を 書きます。

A:いつ 出かけますか。
B:昼ご飯を 食べてから 出かけます。

A:すみません、この 荷物を 中国ヘ 送って くださいい。
B:船便ですか、航空便ですか。
A:船便で お願いします。

A:この バスは 駅前を 通りますか。
B:はい、通ります。
----
