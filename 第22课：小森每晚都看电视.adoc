== 语法

=== 敬体形和简体形

在日语里，日语的形式形式根据说话人和听话人之间的上下关系、亲属关系的不同而不同。迄今为止学习的“~ます”、“~です”是对长辈或者关系不太亲密的人使用的形式。这种形式我们称作“敬体形”。与此相反，如对方是自己的同辈或者晚辈，或者关系较为亲密时则使用“简体形”。是不使用“ます”、“です”的形式。

动词本身具有“敬体形”和“简体形”，如以前学过的“~ます”、“~ません”、“~ました”、“~ませんでした”等四种礼貌的表达形式即是“敬体形”，而以前所学的动词“基本型”、“ない形”、“た形”都属于简体形。但一类形容词、二类形容词和名词本身没有“敬体形”和“简体形”之分，只有在谓语时，其他谓语形式才具有“敬体形”和“简体形”。

=== 动词的简体形

|===
|||敬体形|简体形|敬体形|简体形

.2+h|现在将来形式 h|肯定|買い増す|買う（基本形）|あります（有）|ある
h|否定|買いません|買わない（ない形）|ありません|ない
.2+h|过去形式 h|肯定|買いました|買った（た形）|ありました|あった
h|否定|買いませんでした|買わなかった（なかった形）|ありませんでした|なかった
|===

----
* 森さんは 毎晩 テレビを 見る。
* コーヒー、飲む？
-ううん、飲まない。
* 昨日 テレビ、見た？
-ううん、見なかった。 
----

注：简体的会话中常常省略助词。另外，“あります”的简体形是“ない”。
