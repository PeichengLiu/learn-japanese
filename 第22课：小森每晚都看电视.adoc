== 语法

=== 敬体形和简体形

在日语里，日语的形式形式根据说话人和听话人之间的上下关系、亲属关系的不同而不同。迄今为止学习的“~ます”、“~です”是对长辈或者关系不太亲密的人使用的形式。这种形式我们称作“敬体形”。与此相反，如对方是自己的同辈或者晚辈，或者关系较为亲密时则使用“简体形”。是不使用“ます”、“です”的形式。

动词本身具有“敬体形”和“简体形”，如以前学过的“~ます”、“~ません”、“~ました”、“~ませんでした”等四种礼貌的表达形式即是“敬体形”，而以前所学的动词“基本型”、“ない形”、“た形”都属于简体形。但一类形容词、二类形容词和名词本身没有“敬体形”和“简体形”之分，只有在谓语时，其他谓语形式才具有“敬体形”和“简体形”。

=== 动词的简体形

|===
|||敬体形|简体形|敬体形|简体形

.2+h|现在将来形式 h|肯定 |買い増す |買う（基本形） |あります（有） |ある
h|否定 |買いません |買わない（ない形） |ありません |ない
.2+h|过去形式 h|肯定 |買いました |買った（た形） |ありました |あった
h|否定 |買いませんでした |買わなかった（なかった形） |ありませんでした |なかった
|===

----
* 森さんは 毎晩 テレビを 見る。
* コーヒー、飲む？
-ううん、飲まない。
* 昨日 テレビ、見た？
-ううん、見なかった。 
----

注：简体的会话中常常省略助词。另外，“あります”的简体形是“ない”。

=== 一类形容词谓语形式的简体形

|===
|||敬体形|简体形

.2+h|现在将来形式 h|肯定|忙しいです（忙） |忙しい
h|否定|忙しくないです |忙しくない
.2+h|过去形式 h|肯定|忙しかったです|忙しかった
h|否定|忙しくなかったです|忙しくなかった
|===

----
* その カレー、おいしい？
-ううん、あんまり おいしく ないよ。
* 昨日の 試験、どうだった？
-ちょうと 難しかった。
----

=== 二类形容词谓语形式的简体形

|===
|||敬体形|简体形

.2+h|现在将来形式 h|肯定 |簡単です（简单） |簡単だ
h|否定 |簡単ではありません |簡単ではない
.2+h|过去形式 h|肯定 |簡単でした |簡単だった
h|否定 |簡単ではありませんでした |簡単ではなかった
|===

现在将来形式的肯定疑问句用去掉简体形式的“だ”的形式（名词也一样）。

----
* この ネクタイ、派手？
-ううん、全然 派手じゃ ないわ。
* 森さんの アパート、静か？
-うん、静かだよ。
----

=== 名词谓语形式的简体形

|===
|||敬体形|简体形

.2+h|现在将来形式 h|肯定 |晴れです（是晴天） |晴れだ
h|否定 |晴れではありません |晴れではない
.2+h|过去形式 h|肯定 |晴れでした |晴れでった
h|否定 |晴れではありませんでした |晴れではなかった
|===

----
* 今日は 曇りだ。
* 明日は 水曜日だね。
-水曜日じゃないよ。木曜日だよ。
* 昨日、スキー場は 雪だった？
-ううん、雪じゃなかったよ。いい 天気だった。
----

=== 小句けど，小句（转折）（铺垫）

“けど”连接两个句子，表示转折，起着把两个句子归纳成一个句子的作用，用口语。

----
* 昨日の 試験、どうだった？
-ちょうと難しかったけど、まあまあ できたよ。
----

另外，けど“”还有不表示转折而表示铺垫的用法。

----
* 来週、送別会を するけど、都合は どうかな？
----

== 课文

----
A:明日 ボーリングに 行かない？
B:ごめん。明日は 仕事が あるから……。

A:昨日の 試験、どうだった？

A:この ネクタイ、派手？
B:ううん、全然 派手じゃないわ。

A:森さんの 電話番号、知ってる？
B:うん、知ってる。3493-3945だよ。
----
